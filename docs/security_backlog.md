# План внедрения функций безопасности

Этот документ фиксирует обязательные шаги по реализации ключевых механизмов безопасности платформы. Пункты структурированы по компонентам и статусам выполнения. Заполняйте поле «Статус» по мере продвижения и добавляйте ссылки на задачи/PR.

## Аутентификация и авторизация

| Функция | Описание | Статус |
| --- | --- | --- |
| OAuth2 / OIDC | Выбрать провайдера (Keycloak/Auth0/AWS Cognito), настроить PKCE, конфигурировать доверенные redirect-uri, описать пользовательские роли и матрицу разрешений. | ☐ Не начато |
| Refresh-токены | Реализовать защищённое хранение refresh-токенов, ротацию, blacklisting при отзыве доступа и ограничения по устройствам. | ☐ Не начато |
| API-ключи | Сгенерировать модель для ключей сервиса, добавить ограничения по scope и сроку действия, обеспечить просмотр и отзыв в кабинете администратора. | ☐ Не начато |

## Контроль доступа к API

| Функция | Описание | Статус |
| --- | --- | --- |
| Rate limiting | Настроить Redis/Upstash с токен-бакетом для публичных эндпоинтов, выделить отдельные квоты для фоновых задач и админ-интерфейса. | ☐ Не начато |
| CORS policy | Сформировать whitelist доменов, поддержать preflight, включить строгие заголовки (`Access-Control-Allow-Origin`, `Vary`, `Access-Control-Allow-Credentials`). | ☐ Не начато |

## Наблюдаемость и аудит

| Функция | Описание | Статус |
| --- | --- | --- |
| Аудиторный лог | Добавить сервис аудита с записью действий пользователей/сервисов (CRUD, входы, изменение настроек), хранить в append-only хранилище и обеспечить экспорт. | ☐ Не начато |
| Мониторинг безопасности | Создать алерты на аномалии входов, превышение лимитов и системные ошибки авторизации. | ☐ Не начато |
