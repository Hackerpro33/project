# Руководство по экстренной ротации секретов

1. Создайте инцидент в системе управления (Jira/YouTrack) с пометкой `security`.
2. Соберите рабочую группу (security, платформенная команда, владелец сервиса).
3. Сгенерируйте новые значения секретов и обновите SOPS-файл для соответствующего окружения.
4. Запустите пайплайн GitOps/CI, убедитесь, что новые значения доставлены во все среды.
5. Проверьте журналы доступа и зафиксируйте результаты расследования в разделе `history` шаблона.
6. По завершении уведомите заинтересованные стороны и обновите документацию при необходимости.
